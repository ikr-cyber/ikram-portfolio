🎯 Introduction à Nagios
Concepts fondamentaux et architecture
ℹ️
Nagios Core est un logiciel open-source de supervision réseau qui surveille continuellement les serveurs, services et applications. Il détecte les problèmes et envoie des alertes en temps réel.
📊 Architecture générale

Nagios fonctionne selon ce principe simple :

⬡ CYCLE DE FONCTIONNEMENT
1. Vérification (Check) Nagios exécute un plugin pour vérifier un hôte ou service (ex: vérifier si Apache répond)
2. Évaluation Résultat = OK (0), WARNING (1), CRITICAL (2), ou UNKNOWN (3)
3. Notification Si CRITICAL, envoyer alerte (email, SMS, Slack, etc.)
4. Affichage Interface Web pour visualiser l'état de tous les hôtes/services en temps réel
🛠️ Composants de Nagios
ComposantFonction
Nagios CoreMoteur de supervision, planification des vérifications
PluginsScripts qui vérifient l'état des services (check_ping, check_http, etc.)
Configuration FilesFichiers .cfg qui définissent hôtes, services, seuils d'alerte
Web InterfaceInterface Apache pour visualiser le statut (nagios.cfg)
NotificationsSystème d'alertes (email, contacts définis)

⚙️ Installation complète
Ubuntu 22.04 LTS — Étape par étape
📌
Prérequis : Ubuntu 22.04 LTS, sudo access, connexion Internet, 2GB RAM min, 5GB disque
Étape 1 — Installer les dépendances
ubuntu@nagios-server:~
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential libgd-dev libmcrypt-dev libssl-dev bc gawk dc gettext
sudo apt install -y apache2 apache2-utils
sudo apt install -y postfix mailutils
Étape 2 — Créer l'utilisateur Nagios
création utilisateur
sudo useradd nagios
sudo groupadd nagcmd
sudo usermod -a -G nagcmd nagios
sudo usermod -a -G nagcmd www-data

📚 Glossaire — Terminologie Nagios
Définitions des termes importants
Host
Un ordinateur, serveur ou appareil réseau surveillé par Nagios (ex: 192.168.1.100)
Service
Un élément à surveiller sur un hôte (ex: HTTP, SSH, Disk Space, CPU Load)
Plugin
Script exécutable qui vérifie l'état d'un hôte/service (ex: check_http)
Check
Exécution d'une vérification (lancer un plugin et récupérer le résultat)
Hard State / Soft State
Hard = état définitif après max_check_attempts. Soft = tentative temporaire
Contact
Personne qui reçoit les notifications (email défini dans contacts.cfg)
Notification
Alerte envoyée à un contact lorsque un service passe en CRITICAL
Event Log
Fichier journal contenant tous les événements du système (nagios.log)
